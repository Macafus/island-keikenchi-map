# island-keikenchi-map
# 法定有人離島・訪問記録マップ

ブラウザで `index.html` を開きます。Rは不要です。地図タイルの読み込みにはインターネット接続が必要です。

## 対象定義

対象は、次の4制度で振興等の対象となる有人島の合算です（303島）。

1. 離島振興法: 255島
2. 小笠原諸島振興開発特別措置法: 2島
3. 奄美群島振興開発特別措置法: 8島
4. 沖縄振興特別措置法: 38島

`islands-data.js` には303島すべてのGeoJSONポリゴンを収録済みです。`island_id` は更新時にも変更しない一意のIDです。

離島振興法分は国土数値情報 A19s（2010年）を基礎に、国土交通省の現行指定一覧（令和8年4月1日）と照合して更新しています。小笠原・奄美・沖縄分は国土数値情報 C23 海岸線（2011年）から照合したポリゴンです。海岸線データの年代差による微小な形状差はあります。

| 列 | 内容 |
|---|---|
| `island_id` | 不変の一意ID |
| `island_name` | 島名 |
| `prefecture` / `municipality` | 集計・表示に使う行政区分 |
| `law` | 上記4制度名のいずれか |
| `geometry` | 島の実際の海岸線ポリゴン（WGS84 GeoJSON） |

## 記録と集計

島の輪郭をクリックし、0〜4の状態を選んで保存します。記録はブラウザのローカルストレージに保存され、再表示後も維持されます。

「地図をシェアする」では、現在の塗り分け地図と寄港以上の島一覧を確認できます。URLには全島の記録が埋め込まれるため、そのURLを開いた相手にも同じ記録が表示されます。

達成率は、選択中の範囲について `状態点の合計 / (島数 × 4) × 100` で算出します。「訪問以上」は「訪問・宿泊・居住」の島数です。

背景地図は国土地理院の淡色地図です。公開時は画面に表示される出典表記を残してください。
