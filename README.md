# 離島経県値マップ

日本の法定有人離島303島を対象に、訪問の記録を残せる地図です。

**[地図を開く](https://macafus.github.io/island-keikenchi-map/)**

## できること

- 島の輪郭をクリックして、訪問状況を記録
- 全国・都道府県別の合計点と達成率を表示
- 現在の記録を含むURLを作成して、XやURLコピーで共有

## 使い方

1. 地図上で記録したい離島の輪郭をクリックします。  
2. 「記録」から、未踏・寄港・訪問・宿泊・居住のいずれかを選びます。  
3. 「この記録を保存」を押すと、地図の色と合計点・達成率が更新されます。  

記録は利用しているブラウザ内に保存されるため、次回開いたときも同じ端末・同じブラウザであれば引き継がれます。

「地図をシェアする」では、現在の記録を反映した地図と寄港以上の離島一覧を確認できます。共有URLをコピーするか、Xへの投稿ボタンを利用してください。

## 記録の種類

| 状態 | 点数 | 地図の色 |
|---|---:|---|
| 未踏 | 0点 | 灰色 |
| 寄港 | 1点 | 青色 |
| 訪問 | 2点 | 黄色 |
| 宿泊 | 3点 | 赤色 |
| 居住 | 4点 | 桃色 |

達成率は、選択範囲の合計点を「対象島数 × 4点」で割って算出します。

## 対象となる有人離島

次の4制度で対象とされる有人離島を合算しています（計303島、令和8年4月1日基準）。

- 離島振興法：255島
- 小笠原諸島振興開発特別措置法：2島
- 奄美群島振興開発特別措置法：8島
- 沖縄振興特別措置法：38島

## データと地図

- 背景地図：国土地理院「地理院タイル（淡色地図）」
- 離島振興法分のポリゴン：国土数値情報 A19s 島嶼単位（2010年）を基礎に現行の指定一覧と照合
- 小笠原・奄美・沖縄分のポリゴン：国土数値情報 C23 海岸線（2011年）を基礎に作成

海岸線データの年代差により、現在の海岸線とわずかな差がある場合があります。

## 記録について

訪問記録は利用しているブラウザ内に保存されます。共有URLを開くと、そのURLに含まれる記録状態が地図に反映されます。個人情報をサーバーへ送信・保存する仕組みはありません。
